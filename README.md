# Journal Application*

Smart Journal is a backend application where users can create and manage their personal journal entries.
I am building this project with Java and Spring Boot while exploring different backend technologies and concepts such as MongoDB, Spring Security,
Redis, Kafka, testing, and deployment.
The project is being developed step by step, with new features being added as  I learn and implement them.

# Features
# Currently Working On
- Create journal entries
- View journal entries
- Update journal entries
- Delete journal entries
- Store journal data in MongoDB

# Planned Features
